# References

## 1. Academic Papers

### 1.1 LDPC Codes and Decoding

1. Gallager, R. G. (1962). "Low-density parity-check codes." IRE Transactions on Information Theory, 8(1), 21-28.
   - Foundational paper on LDPC codes
   - Introduces basic concepts and properties
   - Historical significance

2. MacKay, D. J. C., & Neal, R. M. (1996). "Near Shannon limit performance of low density parity check codes." Electronics Letters, 32(18), 1645-1646.
   - Rediscovery of LDPC codes
   - Performance near Shannon limit
   - Practical implementation insights

3. Richardson, T., & Urbanke, R. (2001). "The capacity of low-density parity-check codes under message-passing decoding." IEEE Transactions on Information Theory, 47(2), 599-618.
   - Theoretical analysis of LDPC codes
   - Message passing decoding
   - Performance bounds

### 1.2 Neural Network Decoders

1. Nachmani, E., Be'ery, Y., & Burshtein, D. (2016). "Learning to decode linear codes using deep learning." IEEE Transactions on Signal Processing, 64(17), 4413-4427.
   - Early work on neural network decoders
   - Deep learning approach
   - Performance improvements

2. Gruber, T., Cammerer, S., Hoydis, J., & Brink, S. (2017). "On deep learning-based channel decoding." IEEE Journal of Selected Topics in Signal Processing, 12(1), 119-131.
   - Deep learning for channel decoding
   - Architecture design
   - Performance analysis

3. Cammerer, S., Gruber, T., Hoydis, J., & Brink, S. (2017). "Scaling deep learning-based decoding of polar codes via partitioning." IEEE Transactions on Communications, 65(6), 2749-2760.
   - Scaling deep learning decoders
   - Partitioning techniques
   - Implementation insights

### 1.3 Residual Connections and Weight Sharing

1. He, K., Zhang, X., Ren, S., & Sun, J. (2016). "Deep residual learning for image recognition." IEEE Conference on Computer Vision and Pattern Recognition (CVPR), 770-778.
   - Residual connections
   - Deep learning architecture
   - Training benefits

2. Huang, G., Liu, Z., van der Maaten, L., & Weinberger, K. Q. (2017). "Densely connected convolutional networks." IEEE Conference on Computer Vision and Pattern Recognition (CVPR), 4700-4708.
   - Dense connections
   - Network architecture
   - Feature reuse

3. Zagoruyko, S., & Komodakis, N. (2016). "Wide residual networks." British Machine Vision Conference (BMVC).
   - Wide networks
   - Residual learning
   - Performance analysis
